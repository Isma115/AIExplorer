
[TAREA 1] Crea una web inicial en la que se va a mostrar una interfaz de chat moderna estilizada con estilos únicos CSS que se van a aplicar globalmente a toda la web en el futuro. La interfaz de chat es la de un chat simple clásico para enviar mensajes y que sean respondidos, con un historial de conversación que es un área dónde se van a incluir los mensajes que se envían y los que se reciben, en orden, los que se envían en la parte derecha de la pantalla y los que se reciben en la parte izquierda de la pantalla. Además habrá un botón de enviar mensajes y un área de texto para escribir los mensajes, etc. El diseño debe de ser único, original y no utilizar ninguna librería externa para estilos, etc. por lo que deberemos de utilizar tailwindcss o similar para estilos globales.

[TAREA 2] El proyecto tendrá que tener un servidor corriendo para poder realizar toda la gestión de recursos, por lo que voy a preferir construir el proyecto haciendo uso de React y NodeJS para el backend

[TAREA 3] Toda la parte de backend debería de utilizarse solamente para gestionar la base de datos haciendo uso del ORM de NodeJS pero ahora mismo hay lógica de frontend en esta parte del proyecto, por lo que ahora mismo ya que no hay gestión de base de datos, la lógica de backend debería de estar vacía, mientras que el frontend debe gestionar la lógica del funcionamiento normal de la parte de frontend

[TAREA 4] Añade un panel lateral izquierdo que de momento guarde el historial de conversaciones del usuario, por lo que se va a permitir crear nueva conversación vacía e ir guardando cada estado de la conversación, de momento esta información guardada de cada conversación quedará guardado en local

[TAREA 5] Cambia el aspecto visual de toda la página por un aspecto más moderno pero original similar a otros chat de IA como los de ChatGPT o Grok similares, implementa estilos modernos y limpios, pero originales.
